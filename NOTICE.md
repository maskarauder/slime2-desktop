# Independent fork notice and credits

## Project identity

**Slippy2 Desktop** is an independent derivative of
[Slime2 Desktop](https://github.com/zaytri/slime2-desktop), originally developed
by [Zaytri](https://zaytri.com/). Maskarauder maintains this repository and its
modified releases. This fork is not affiliated with, supported by, or endorsed
by Zaytri or the upstream Slime2 project.

This fork includes contributions developed with generative-AI assistance.
Responsibility for this fork's changes, releases, and support belongs to its
maintainer and contributors, not to the upstream author.

## Detachment and upstream policy

As read on October 13, 2026, the
[upstream README](https://github.com/zaytri/slime2-desktop#readme) states that
repository contents are not to be used in machine-learning models and that
forks and pull requests containing generative-AI-assisted contributions will
not be accepted.

Maskarauder chose to detach this repository from GitHub's upstream fork network
in response to that published policy and to make its independent status clear.
The upstream author did not contact Maskarauder directly to request detachment.
Detachment changes the GitHub repository relationship; this project remains
derived from Slime2 Desktop. This notice records the upstream position and this
fork's provenance; it does not claim permission or endorsement from the author
for AI-assisted development or use of their work in machine-learning models.

Please send issues and support requests for this fork to
[this repository](https://github.com/maskarauder/slime2-desktop/issues), not to
upstream. Do not submit this fork's AI-assisted contributions upstream in
conflict with the upstream contribution policy.
